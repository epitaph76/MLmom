# Исправления агентского ML-пайплайна: итог реализации

Ветка codex/universal-agent-pipeline. Исходная версия — 8b962e8; артефакты остановленного прогона сохранены. Runtime v3 требует нового run-каталога.

## Изменения

- Начальные модели и приоритеты выбирают агенты для задачи. Подготовка независимых кандидатов выполняется параллельно с изолированными настройками ролей и общим учётом CPU/RAM.
- Feature Engineer предлагает признаки после контекста; затем они измеряются на замороженном контроле до длительного HPO. Первоначальный baseline сохраняется.
- Первый успешный baseline выпускает full-train CSV. Оценочные модели не заменяют его; последующая публикация атомарна.
- Optuna выбирает числа, Training agent управляет continue/stop/refit и additional_trials. Startup TPE — 3, пакеты — 5; порог 0,5% предлагает завершение с правом агента продолжить. Явный пользовательский максимум сохраняется.
- Совместимый baseline, включая участника семьи до outer evaluation, импортируется без повторного fit. Проверяется совместимость кэша; несовпадение запускает обычный поиск. CPU-потоки отделены от обучающих параметров, исходные selection-артефакты сохраняются.
- Ensemble agent явно выбирает рецепты. Python сохраняет исправления Planner и не добавляет OOF/подбор весов к mean. Валидатор получает текущий SDK/DSL, источник полей и изменения плана.
- Ошибки возвращаются ответственным ролям. Изменённый код можно ремонтировать дальше; повтор неизменённого исполнения с той же ошибкой откладывается. Идентичный неудачный SQL возвращает сохранённую ошибку.
- Остановка отменяет ожидающие задачи и активные процессы, блокирует поздние ответы и сохраняет interrupted/external_stop отдельно от result_available. Готовый full-train файл сохраняется.
- Проверены все 33 skills, manifests, REFERENCE.md и передаваемые роли. Исправлены устаревшие требования обязательного экспорта/аудита и владельцы преобразований. Правило совместного обновления закреплено в AGENTS.md.

Контракты: [AGENT_PIPELINE_V3_RU.md](AGENT_PIPELINE_V3_RU.md). Аудит: [SKILLS_AUDIT_AGENT_PIPELINE_RU.md](SKILLS_AUDIT_AGENT_PIPELINE_RU.md).

## Реальные API-прогоны

Модель deepseek/deepseek-v4.1-flash-1017, RouterAI. Небольшие синтетические данные: regression/text train 540 строк, multiclass train 900 строк, test по 100 строк. Диагностический HPO ограничен пятью новыми trials на study; общего дедлайна и token cap не было. Эти оценки не сравниваются с исходными датасетами прогона.

| Сценарий | Цикл, мин:сек | Первый full-train CSV | Outer holdout | Измерений признаков | Перенос и replay |
|---|---:|---:|---|---:|---|
| Регрессия | 8:59 | 4:07 | rmse 4.004063 | 2 | passed |
| 10 классов | 6:40 | 3:59 | f1_macro 0.645320 | 2 | passed |
| TF-IDF + линейная модель | 7:25 | 5:21 | f1_macro 1.000000 | 2 | passed |

Все три: сохранён submission_refit, схема и порядок ID корректны, перенесённая модель воспроизводит CSV. Сохранённые наблюдения достигли Context agent и Hypothesis Generator. Текстовый путь использовал только sklearn; разреженная матрица 100×81 сохранена.

Usage завершённых запросов: prompt **950766**, completion **277075**, всего **1227841** токенов. Provider cost **28.9076208516**, валюта провайдером не указана. [Машинный отчёт](../artifacts/universal-real-v3/report.json); trace, модели, CSV, trials и исходники кандидатов лежат в соответствующих case/run каталогах.

## Ошибки и границы доказательств

- Первичная независимая проверка упала из-за относительного пути диагностического скрипта. Исправлены абсолютный путь и явная проверка одного цикла; стандартная release-проверка сохраняет требование трёх циклов. Повторены только загрузка и inference, без обучения и платных вызовов. Исходные failed-отчёты сохранены как report.initial.json и verification.initial.json.
- Три решения Training agent запросили расширение сверх явного диагностического trial limit. Сработала программная политика; поиск продолжился в разрешённом бюджете. Эти ответы не скрыты как корректные.
- В текстовом сценарии зафиксирована ошибка сгенерированного кандидата при проверке NumPy-массива как bool; traceback передан кодеру. Готовый результат сохранён; исходная ошибка остаётся в trace.
- Неудачных CSV jobs: regression 0, multiclass 2, text 1. Успешный итог не означает отсутствия ошибок инструментов.
- API-прогоны выполнены на snapshot d50b2ff7…. После их старта исправлены trace самостоятельного параллельного клиента и повторное использование семейного baseline. Последние изменения проверены полным suite окончательной версии и сохранёнными реальными артефактами; три платных прогона не повторялись. [Точные версии](../artifacts/universal-real-v3/source-version.json); исходный API-runtime ZIP сохранён.
- Прирост качества на других данных не обещается. Forecasting и новые типы задач не добавлялись.
