# Как сейчас работает MLmom

Текущая ветка: [агенты и технический минимум](MINIMAL_CHECKS_RU.md).

solution.py → Inspector → разведчик/confirm_task → Context agent → гипотезы → Planner →
LLM plan_validator → агенты предобработки/модели → синтаксис/интерфейс → Worker →
внутренняя validation/HPO и training_agent → refit → внешний score → Champion → CSV.

Feature agent работает каждый цикл. Ensemble agent предлагает композиции сохранённых моделей.
Result validator и повторная разведка передают рекомендации следующему циклу.
Отчёты об исполнении, AST-политики и доказательства эквивалентности не являются этапами допуска.

Профиль, SQL-расчёты и метрики по-прежнему вычисляет Python. Это вычисления и данные для
агентов; постановка, приоритеты и методологический review принадлежат агентам.
Ресурсы, разделение данных, форматы прогнозов/CSV и восстановление сохраняются.
