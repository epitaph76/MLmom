# Проверено 19.10.2026

Windows, Node 24.21.0, Python 3.14.7: зависимости установлены, `npm run setup` и `npm run check` выполнены успешно: 10 TypeScript- и 12 Python-тестов. Проверка launcher подтверждает запуск Pi Web и обоих API, затем закрытие всех трёх портов при остановке; GitHub Actions настроен на Windows и Linux, удалённые прогоны ещё не выполнялись.

RouterAI с указанной моделью прошёл отдельный smoke-тест: текстовый ответ, streaming и вызов `get_capabilities` через Pi. В Pi Web вручную проверена цепочка `get_capabilities → research → get_research_status(wait=true)`; задание завершилось `succeeded`, интерфейс показал синтетическую карточку и пояснение `mock=true`.

Реальное обучение, внешний поиск тиммейта, MLflow и Research KB не проверялись: их реализация не входит в этот этап. Проверка RouterAI подтверждает совместимость в момент запуска, а не доступность внешнего сервиса в будущем.
