# Архив для загрузки

`mlmom-solution.zip` содержит `solution.py`, `requirements.txt`, `mlmom_bundle.py`. Платформа запускает решение отдельно для каждой задачи с API-подключением из окружения.

**94 теста прошли на извлечённом финальном ZIP.** Обе исходные организаторские задачи прошли реальную Qwen, LLM-кодер, обучение, финальное переобучение и независимую загрузку моделей. Исправлены история API, tool loops, стартовый кандидат, бюджеты ролей, обработка валидатора, ссылки версий, обязательные исключения и временные 5xx.
