# Тестовая загрузка

## Архив

Загрузите `mlmom-solution.zip` в Boosters: архив содержит три корневых файла и не требует установки пакетов при запуске. Ключи платформа подставляет через окружение; в архиве их нет.

## Текущие проверки

45 тестов финального ZIP прошли в Linux без сети на 8 CPU и 32 GB RAM, включая девять реальных адаптеров и сквозные раунды с mock LLM. В архив входят все 17 готовых скиллов, их manifests и общий контракт; размер, SHA256 и исходный commit находятся в [validation.json](validation.json).

## Предыдущие запуски

До заполнения скиллов оба полных архива организаторов прошли два раунда с mock LLM, а реальная Qwen сформировала regression submission на 22 449 строк после evaluation и полного refit. Текущие скиллы через платный API, трёхчасовой стресс-прогон и загрузка в Boosters пока не проверялись; подробности приведены в [отчёте](../VALIDATION.md).

## Пересборка

Команда `python scripts/package_solution.py --output dist/mlmom-solution.zip` собирает архив из текущих исходников репозитория. Контроль состава выполняется в `tests/test_packaging.py`; проверенная копия для загрузки хранится здесь.
