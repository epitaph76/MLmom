# Тестовая загрузка

## Архив
Загрузите `mlmom-solution.zip` в Boosters: архив содержит три корневых файла и не требует установки пакетов при запуске. Ключи платформа подставляет через окружение; в архиве их нет.

## Проверки
38 тестов финального ZIP прошли в Linux без сети на 8 CPU и 32 GB RAM; оба архива организаторов прошли два раунда с mock LLM. Реальная Qwen сформировала regression submission на 22 449 строк после evaluation и полного refit, с повторной проверкой кандидата финальным worker.

## Условия API-проверки
Генерация, планирование, код, обучение и оценка выполнены через настоящий API; ранее проверенные постановка и пробы библиотек восстановлены для тех же входов. Трёхчасовой стресс-тест и загрузка в Boosters не выполнялись; подробности и SHA256 находятся в [validation.json](validation.json).

## Пересборка
Команда `python scripts/package_solution.py --output dist/mlmom-solution.zip` собирает архив из текущих исходников репозитория. Для контроля состава используются `tests/test_packaging.py` и хеш в отчёте.
