# Проверка реализации

## Текущий ZIP — 20 октября 2026

45 тестов кода, извлечённого из `submission/mlmom-solution.zip`, прошли за 164,819 секунды в Linux с Python 3.12, зависимостями организаторов, 8 CPU и 32 GB RAM при отключённой сети. Проверены девять реальных ML-адаптеров, сквозные раунды с mock LLM, HPO, split, Champion, процессы, восстановление, SDK и сохранность submission.

## Скиллы и планирование

Все 17 скиллов имеют статус `ready`, версию `1.0.0` и занимают вместе с общим контрактом 23 646 из 24 000 символов. Проверены доставка инструкций ролям планирования и кодеру, `read_skills`, совместимость, зависимости, хеши, лимит контекста и отклонение несовместимых пар типа задачи и native objective LightAutoML.

## Состав архива

Плоский ZIP содержит `solution.py`, `requirements.txt` и `mlmom_bundle.py`; встроенные исходники, профили и все 35 файлов скиллов совпадают с текущими файлами проекта. Размер, SHA256, исходный commit и результаты проверки секретов записаны в [submission/validation.json](submission/validation.json).

## Архивы организаторов — предыдущая проверка

До заполнения скиллов оба полных архива прошли по два раунда с mock LLM и реальным CatBoost: регрессия на 22 449 строках test и многоклассовая классификация на 41 166 строках. Проверены колонки, порядок ID, допустимые метки и конечность предсказаний; с новым набором скиллов эти полные архивы повторно не запускались.

## Реальный API — предыдущая проверка

До заполнения скиллов Qwen выполнила планирование, генерацию кода, evaluation и полный refit регрессии, сформировав submission на 22 449 строк примерно за 12 минут. Постановка и пробы библиотек были восстановлены из предыдущего реального запуска для тех же файлов; текущие 17 скиллов через платный API пока не проверялись.

## Границы проверки

Трёхчасовой стресс-прогон и отправка в Boosters не выполнялись; исследовательский RMSE не является платформенной оценкой. Текущий ZIP проверен автоматическими тестами с mock LLM, а исторические запуски отдельно отмечены в JSON-отчёте.
