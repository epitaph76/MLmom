# Проверка реализации

## Обновление скиллов — 20 октября 2026

В текущих исходниках 17 английских скиллов `ready`, версия `1.0.0`. Полный набор с общим контрактом занимает 23 646 из 24 000 символов. Все 17 файлов прошли `skill-creator/quick_validate.py`; 44 теста `python -m unittest discover -v` прошли в локальном Python 3.12 на Windows за 218,251 секунды. Проверены автоматическая загрузка базовых инструкций, общий хеш, лимит контекста, совместимость, упаковка, сквозные раунды и восстановление. Тесты используют mock LLM и доступные локальные адаптеры; новый прогон реального API и отсутствующих библиотек не выполнялся.

Актуальная сборка: `dist/mlmom-solution.zip`, SHA256 `0db6b6150f520f2214de64cdd602cdc19444a8adc2e55b52800807213eaef3e9`. Все 35 файлов скиллов в архиве совпадают с исходниками. Исторические результаты прежнего архива приведены ниже.

## Автотесты
38 тестов кода, извлечённого из финального ZIP, прошли за 161,598 секунды в Linux без сети при 8 CPU и 32 GB RAM. Проверены девять реальных ML-адаптеров, ошибки, процессы, HPO, split, Champion, восстановление, SDK и сохранность submission.

## Архивы организаторов
Два полных архива прошли по два раунда с mock LLM и реальным CatBoost: регрессия на 22 449 строках test и многоклассовая классификация на 41 166 строках. Проверены колонки, порядок ID, допустимые метки и конечность предсказаний.

## Реальный API
Qwen выполнила планирование, генерацию кода, evaluation и полный refit регрессии, сформировав submission на 22 449 строк; run занял около 12 минут. Постановка и пробы библиотек восстановлены из предыдущего реального запуска для тех же файлов, а готовый кандидат повторно проверен финальной версией worker без API.

## Границы проверки
Трёхчасовой стресс-прогон и отправка в Boosters не выполнялись; исследовательский RMSE не является платформенной оценкой. Приведённые выше проверки и [submission/validation.json](submission/validation.json) относятся к прежнему архиву до обновления скиллов. Текущие исходники содержат 17 английских скиллов `ready`; их автоматическая загрузка, хеширование, совместимость и лимит контекста проверяются в `tests/test_skills.py`, а доставка в плоском ZIP — в `tests/test_packaging.py`. Новый архив собирается в `dist/` командой из README.
